# Предварительный подбор резервного генератора

Самостоятельный статический компонент `/podbor-generatora/`. Первый вариант для проверки владельцем: `noindex,follow`, без добавления в поиск сайта, меню и sitemap. Не менять этот статус до проверки и согласования. Существующие страницы не изменены. Нет внешних библиотек, API, ИИ, голосового автозапуска или передачи заполненных данных на сервер.

## Файлы

- `data.js`: условные редактируемые нагрузки, исходные пресеты, паспортные исполнения и источники.
- `engine.js`: чистые функции расчёта, фильтрации и сравнения. Можно подключать в браузере и Node.
- `component.js`: SVG-пиктограммы, управление, памятка, восстановление состояния из ссылки.
- `component.css`: изолированное оформление, мобильная раскладка и печать.
- `index.html`: страница с существующей шапкой сайта. Использует общие поиск, водяной эффект и `SellerSheet`.

## Расчёт

Все выбранные нагрузки работают одновременно. Ватты — сумма потребляемых P1. Полная мощность — консервативная сумма P1/PF. Это приближение, не расчёт формы тока и фазового сложения нагрузок. Параметры приборов по умолчанию — примеры, не паспортные данные техники посетителя. Флажок «проверены» обозначает заявление владельца, не проверку сайтом.

Одновременные пуски: сумма заданных пусковых ВА (не меньше рабочих ВА). Обеспеченные последовательные пуски: максимум из работы всех приборов и пуска одного при работе остальных. Неизвестный пуск оставляет итог пуска неизвестным. Ошибочные значения блокируют подбор и ссылку на расчёт. Изменение типа своего прибора на двигатель сбрасывает его пуск в «неизвестно».

Номинальные Вт и ВА генератора сравниваются независимо с рабочей нагрузкой и выбранным запасом. 20% — редактируемый пример, не норматив. Пуск сравнивается с номинальными ВА только для справки и сортировки: даже попадание в номинал не гарантирует запуск без проверки провала напряжения, времени пуска и защит. Максимальная мощность никогда не используется для подтверждения пуска. Запас топлива и время работы бака не вычисляются; пожелание по времени только записывается продавцу.

Все исполнения однофазные, 50 Гц. Прибор 380/400 В, неизвестное напряжение или квартира блокируют рекомендации топливных моделей. Балкон не допускается как место работы топливного генератора. Аккумуляторный подбор для квартиры — отдельный будущий инструмент.

## Данные и источники

Паспорта и примечания к каждой цифре доступны в `data.js` и разделе источников на странице. Проверено 21.10.2026. Набор: Honda EU22i / EU30iS; CHAMPION GG3301 / IGG3200 / LPG6500E / GG7501E / DG6501E; архивный Generac PowerPact G006520-1, исполнение 220 В 50 Гц. Не заменять последний похожим американским 60 Гц.

LPG6500E: 5 кВт на бензине, 4,5 кВт на LPG. PowerPact: 5 кВт на природном газе, 5,6 кВт на LPG. LPG и природный газ — разные варианты. Электростартер не равен АВР. Подтверждённая возможность автоматического управления в этой базе есть только у PowerPact, и требует отдельной согласованной системы переключения.

Масса, шум и размеры имеют ограничения конкретного источника. Шум разных видов и условий не превращается в общий рейтинг. Цены, наличие, ресурс, местная гарантия и рейтинг качества не придуманы. Для аналога продавец должен сверить собственный паспорт, не переносить данные образца на похожий корпус.

Размещение: рекомендации МЧС и CDC приведены на странице. Схему подключения дома проверяет электрик, газовое подключение — профильный специалист. Калькулятор не выдаёт монтажных инструкций.

## Проверка

```sh
node podbor-generatora/test.cjs
node --check podbor-generatora/component.js
node --check podbor-generatora/data.js
node --check podbor-generatora/engine.js
node scripts/build-static.mjs
```

Тест проверяет 512 сочетаний нагрузки, Вт/ВА, одновременные и последовательные пуски, неизвестные и ошибочные исходные значения, запрет подбора для квартиры/трёхфазного прибора, разницу топлива и отсутствие влияния «максимальной мощности» на оценку пуска.

Дополнительно проверены DOM-сценарии через JSDOM: пресеты, переключение нагрузки без сброса при смене модели, поля, фильтры, экранирование названия своего прибора, отсутствие моделей при неподходящих условиях, памятка на весь экран, закрытие крестиком/Escape, возврат фокуса, копирование и восстановление по ссылке. Реальный браузер и физический смартфон в текущей среде не проверены; перед полной публикацией проверить мобильную раскладку и системное «Поделиться» на телефоне владельца.

Для редактирования нагрузки используйте `data.js`; для новой модели добавьте запись с проверенными `ratings` по каждому топливу и первичным источником. Не выводите расчёт для исполнения с неизвестным номиналом ВА, не подменяйте отсутствующие данные придуманными. Новое оборудование с другой электрической архитектурой требует отдельной модели расчёта.
