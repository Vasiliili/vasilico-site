# Подбор насоса: предварительный вариант 1

НЕ ОПУБЛИКОВАН. Рабочий сайт и GitHub не изменены.

## Как посмотреть
Откройте `index.html` в обычном браузере. Все ресурсы локальные, установка и сервер не нужны.
Отдельный файл `pump-selector-preview.html` содержит этот же компонент и изображения целиком внутри одного файла.

## Реализовано
- Сценарий центрального водопровода, вход 0,5 бар.
- Wilo PB-201EA 50 Гц и эталонный режим без насоса; пять независимых потребителей плюс колонка как путь горячей воды.
- Пять приборов и колонка управляются нажатием; при включении колонки открывается выбранный горячий кран, если он был закрыт.
- Два манометра 0–10 бар, плавное изменение стрелок, шкала 1–4 бар с обработкой выхода за пределы.
- H(Q), зависимый от давления расход, последовательные потери в общей трубе, потери ветвей и подъём.
- Проверка естественного протока для запуска, остановка при закрытии воды.
- Настройка условных расходов, высоты, потерь; подробности по каждой точке.
- Неподтверждённая колонка не получает ложную зелёную оценку.
- Клавиатурные кнопки, aria-pressed, status, reduced-motion, адаптивные 6/2 колонки.

## Файлы
- `data.js`: насосы, кривые, автоматика, параметры приборов, шкала, параметры труб, ссылки на первичные источники.
- `engine.js`: чистые расчётные функции без DOM. Выходные давления, расходы, состояние автоматики и колонки.
- `component.js`: управление, манометры и отрисовка труб. Новые модели через данные, без изменения схемы.
- `component.css`: оформление в цветах сайта; размеры и адаптация.
- `index.html`: интерфейс и пояснения; подключение не зависит от chatgpt.site.
- `test-engine.cjs`: тесты 32 сочетаний, отсутствие двойного расхода колонки, запуск, отсутствие расхода, ограничение H(Q), ползунок тестовой регулируемой модели.
- `assets/`: фото насоса и исходные графики для сверки.

## Происхождение данных и существенные ограничения
Фото: https://cms.media.wilo.com/dcipicpfinder/wilo236365/2310993/wilo236365_2.png
Кривая: каталог Wilo Korea, https://download.wilo.co.kr/catalog_download.php?catalog=30 , печатная стр.15. Таблица стр.14.
Проверено 14 октября 2026 UTC. Точки вручную приближённо сняты с графика: (0,15), (10,14.7), (20,13.5), (30,11.8), (40,9.6), (50,7), (60,4.1), (70,1), л/мин и м.
Таблица указывает 65 л/мин при 0,5м, что не согласуется с краем нарисованного графика. НЕ исправляли это выдуманными точками: рабочий участок прототипа ограничен 60 л/мин. Перед реальным рекомендательным подбором требуется сверка конкретного исполнения/паспорта и, желательно, числовая характеристика изготовителя.
Европейская карточка PB-201EA 3068136 указывает максимальное рабочее давление 2 бар; корейский каталог отдельно указывает входное 2 бар. Эти понятия не отождествляются. При замене модели обязательно сверять артикул, частоту, присоединения и документацию.
Порог потока 2л/мин взят из описания Wilo PB. Нет проверенного гистерезиса/пассивного сопротивления: они не выдуманы, задержки не моделируются.
Условные расходы и коэффициенты потерь — настройки демонстрации, НЕ нормативы и не паспортные значения оборудования. Все точки на одной высоте по умолчанию. Давление входа считается постоянным при любом расходе.
Модель колонки отсутствует; её сопротивление не задано. Расчёт горячей воды оптимистичный, автоматическое обещание включения запрещено. Настройки heater можно заполнить только проверенными данными конкретной колонки.
Нет моделирования гидроудара, накопления воды, запертого давления, нестабильных режимов и температурного смешения.

4. Реальные регулируемые станции: двигатель содержит ограничение уставки характеристикой, но ни одна такая станция пока не добавлена. Конфигурация regulation={min,max} включает ползунок. Не подставлять релейную станцию как постоянное давление. Неизвестный тип автоматики блокируется.
5. Насосы с реле давления, скважина, бак — отдельные сценарии/динамические модели, пока не реализованы.
6. Только после согласования встраивать в актуальный checkout сайта, добавлять ссылки и публиковать. Сохранить header/nav/контакты сайта; компонент можно изолировать iframe либо scope CSS на .pump-demo. ## Проверка
`node test-engine.cjs`
32 сочетания и 32 проверки колонки пройдены. Начальный режим: около 1,95 бар / 7,0л/мин. Все 5 точек: около 1,71 бар / 26,9л/мин при исходных настройках.
Полноценная проверка в графическом браузере в этой среде недоступна; мобильные размеры заданы в CSS, но визуально ещё не подтверждены.

## Редакция 2
Начальное входное давление 1 бар — условие примера, не замер. Пресеты в inletOptions: 0.5, 0.7, 1, 1.5 бар. Смена насоса сохраняет выбранное давление и приборы. Границы комфорта 2–3 бар сохранены. H(Q) не менялась.
Оценка опыта и отзывы находятся отдельно в assessment; числовой рейтинг надёжности не выводится. limitNote показывает расхождения документов по допустимым давлениям: необходим паспорт конкретного исполнения. Зелёная зона не означает подтверждённую допустимость монтажа.
