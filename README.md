# vasilico.ru — готовый статический сайт

Полная копия текущего сайта на 6 октября 2026 года. Все исходные страницы, CSS, JavaScript и изображения сохранены без изменения. Сборка, npm, база данных и сервер ChatGPT не нужны.

## Загрузка на GitHub Pages

1. Распакуйте ZIP на компьютере.
2. Откройте репозиторий для этого сайта в своём GitHub. Если там пока только тестовая заглушка, замените её файлами из архива.
3. Через Add file → Upload files загрузите СОДЕРЖИМОЕ распакованной папки: index.html, CSS, JS, изображения и все папки. Не загружайте сам ZIP и не помещайте сайт во вложенную папку. Подтвердите Commit changes.
4. Убедитесь, что файл CNAME содержит vasilico.ru. Файл .nojekyll также должен лежать в корне; если проводник его скрыл, создайте через Add file → Create new file.
5. Settings → Pages → Build and deployment: Source — Deploy from a branch; Branch — main (или фактическая ветка с файлами); Folder — / (root). Save.
6. Custom domain — vasilico.ru. Дождитесь успешной проверки DNS и выпуска сертификата. Включите Enforce HTTPS, когда настройка станет доступна.
7. Откройте https://vasilico.ru/ и несколько внутренних страниц напрямую. Проверьте поиск в Советах, калькулятор, фотографии и кнопки связи на телефоне без VPN.

## Важное о размещении

Это проект для корня домена vasilico.ru. Пути /style.css, /sovety/ и другие намеренно сохранены: на собственном домене они работают. Предпросмотр по адресу username.github.io/имя-репозитория/ без собственного домена потребовал бы отдельной адаптации путей.

DNS и подтверждение владения доменом на GitHub настраиваются отдельно. Наличие CNAME в архиве не подтверждает, что DNS или публикация уже настроены. Не заменяйте проверочный TXT случайным значением.

Для локального просмотра запустите в папке сайта: python -m http.server 8000
Откройте http://localhost:8000/ . Открытие index.html двойным щелчком не является проверкой сайта: абсолютным путям нужен веб-сервер.

## Содержимое

index.html — главная; style.css — оформление; app.js — страницы и навигация; knowledge.js — статьи и поиск; calculator.js — калькулятор; water-entry.js — эффект воды. Папки uslugi, sovety, ceny, kontakty, o-mastere, raboty и photos содержат страницы и фотографии. Старые материалы также сохранены. robots.txt и sitemap.xml уже используют vasilico.ru.

Внешние переходы оставлены только по назначению, например в мессенджеры. Секретов, учётных данных и служебной конфигурации Sites в архиве нет.

Инструкция GitHub: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

## Обновление цен и страниц

Все суммы прайса находятся в `pricing-data.js`. После изменения цен, статей или шаблонов выполните:

```
node scripts/build-static.mjs
```

Опубликуйте изменённые исходники вместе с обновлёнными HTML. Скрипт обновляет статические цены, состав работ и разметку для поисковиков из тех же данных, которые использует калькулятор. Зависимости устанавливать не требуется.

Отдельный калькулятор: `/kalkulyator/`. Пример готового выбора: `/kalkulyator/?service=zamena-unitaza`. Страница стоимости: `/cena-zamena-unitaza/`. Старый `/ceny/#calculator` сохранён.

## Собственная статистика кнопок

`contact-stats.js` отправляет только нажатия на телефон, WhatsApp, Telegram,
MAX и внешние ссылки Авито. Страница владельца: `/statistika/` (noindex).
Хранилище — отдельные таблицы `vasilico_*` в существующем Supabase;
функция `vasilico-statistics` проверяет JWT приложения и отдельный пароль
перед выдачей отчётов. Публичный anon JWT в JS не даёт доступа к таблицам.
Пароль владельца не хранится в репозитории; в БД хранится только SHA-256
случайного длинного пароля. Для замены сгенерировать новый случайный токен
не менее 24 байт и заменить `vasilico_stats_config.token_hash` через
авторизованный серверный доступ. Не выдавать service_role браузеру.

Серверная схема: `analytics/schema.sql`; обработчик: `analytics/edge.js`.
После изменения обработчика его нужно отдельно развернуть в Supabase
(verify_jwt=true). HTML и JS публикуются через GitHub Pages.
Новая страница сайта должна подключать `/contact-stats.js` с `defer`.

Повторные нажатия ограничены в браузере 30 секундами, в БД — одной записью
на канал/визит/30-секундный интервал, максимум 40 событий за сутки на визит.
Это базовая защита от дублей, не доказательство реального обращения и не
полная защита от целевой накрутки. Ни IP, ни полный URL с параметрами,
ни текст сообщений в таблицу не записываются. Оператор инфраструктуры
может вести собственные технические логи HTTP. Источник визита приблизителен:
приложения могут скрывать referrer. Для точной метки ссылки поддерживается
`?utm_source=avito` (также whatsapp, telegram, max, google, yandex).


## Подбор доступной техники для местных условий

Известные модели — ориентиры по характеристикам, а не обязательные покупки. В рекомендациях оставляем место простым доступным аналогам. Приоритет покупки: соответствие задаче, местные запчасти и ремонт, понятная гарантия. Без графика допустим предварительный выбор по явно обозначенному опыту продавца/мастера; не переносим паспортные цифры образца на аналог и не выдаём отзывы за измерения. Это относится к насосам, станциям, бойлерам, смесителям и другим будущим подборам. Wilo — пример, отдельная страница ему не требуется. Один насос может применяться в разных схемах после проверки источника, автоматики и условий установки.
