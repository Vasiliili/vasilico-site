# Исправление кнопки «Читать отзывы на Авито» — 28 октября 2026

## Причина

Исправлялся готовый `o-mastere/index.html`, но фактическим источником блока отзывов оставался `app.js`: переменная `avitoProfile` содержала устаревший адрес. Общий `reviews()` подставлял его и при сборке `scripts/build-static.mjs`, и при повторном создании main в браузере.

В предыдущем коммите 21ba0f8 исходный HTML уже содержал полный правильный адрес объявления, однако опубликованный HTML и загруженный с домена app.js содержали старый профиль. Проверка опубликованного HTML до изменений и исполнение опубликованного app.js в DOM воспроизвели неправильный href. Предыдущий GitHub Actions run 40755617226 успешно пересобрал и опубликовал артефакт с этим устаревшим значением. Успешная публикация сама по себе не проверяла бизнес-условие ссылки.

Это воспроизводится на свежем запросе без сохранённого DOM; изменение параметра страницы не исправляет константу в скрипте. В проекте не обнаружены регистрация Service Worker или отдельный скрипт, подменяющий именно этот адрес после общего рендерера. Существующий fingerprint app.js обновляется сборкой и теперь указывает на исправленный файл.

## Исправление

В app.js единственный адрес блока отзывов заменён полным адресом владельца; переменная названа avitoReviewsUrl, поскольку она ведёт на объявление, а не на профиль. Существующий reviews() и оформление сохранены. Подпись существующей кнопки и её декоративная стрелка не изменены; второй кнопки или промежуточной страницы не создано.

Точный адрес — в `scripts/seo/avito-review-url.txt`: 621 символ, параметр context — 503 символа. Сборка и тесты требуют побайтового совпадения href с этим файлом, включая весь context.

В sameAs не подставлялась ссылка объявления: сохранён уже указанный владельцем профиль e210c885a007339875bd33366eadb8c0 и существующая Google-карточка. Старый идентификатор остаётся только в отрицательном условии регрессионного теста, а не в рабочих ссылках или артефакте сайта.

## Автоматические проверки

- scripts/seo/avito.cjs: одна существующая кнопка, исходная подпись, точный полный href в собранном HTML, DOM после общего JS-рендерера и подготовленном _site. Проверка включена в npm run check и отдельно запускается после staging в workflow.
- scripts/seo/live.mjs: после публикации проверяется сам href опубликованной страницы, а не только HTTP 200/отпечаток содержимого.
- scripts/seo/avito-live.cjs: скачивает опубликованный HTML и все подключённые внешние скрипты страницы с действующего домена, выполняет их в JSDOM и повторно проверяет единственную кнопку. Статистика собственных проверок исключается. Отчёт сохраняется в .reports/avito-live.json и в артефакте GitHub Actions.
- Дизайн проверен сохранностью исходных CSS и основного HTML; тексты, цены, фото и калькуляторные источники не менялись. Существующие проверки калькуляторов также пройдены.

JSDOM проверяет DOM и исполнение скриптов; это не ручная проверка в Chrome. Интерактивный браузер в этой сессии недоступен.

## Проверка внешнего Авито

Автоматический запрос полного предоставленного URL получил HTTP 200 со страницей **Site Unavailable**, а не содержимым объявления. Поэтому автоматическое открытие объявления на стороне Авито не подтверждено. Успех проверки собственного href не выдаётся за успешное открытие объявления. Адрес взят непосредственно из предоставленного владельцем URL и не сокращён.
