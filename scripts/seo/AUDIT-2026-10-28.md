# Техническая подготовка vasilico.ru — 28 октября 2026

## Исходная архитектура

Статический сайт, репозиторий Vasiliili/vasilico-site, GitHub Pages. Разделы рендерятся общим app.js из knowledge.js и pricing-data.js; калькуляторы — отдельные статические компоненты. Основные тексты большинства страниц уже присутствовали в HTML. Действующий HTML и JavaScript использовали один общий шаблон, но сборка не запускалась автоматически при каждой публикации.

Ответы действующего домена до изменений: главная, robots.txt и sitemap.xml — HTTP 200; случайный несуществующий адрес — настоящий HTTP 404. http://vasilico.ru/ и https://www.vasilico.ru/ переходили на основной HTTPS-домен. Заголовки указывали на GitHub Pages/Fastly; признаков страницы Cloudflare challenge при этих запросах не было. Это не заменяет проверку правил Cloudflare в кабинете и обращений с настоящих IP поисковых роботов.

## Найдено и исправлено

- Раздел /raboty/ был noindex, хотя содержит ссылки на реальные опубликованные работы. Теперь он открыт; демонстрационный /raboty/protechka/ оставлен noindex.
- В sitemap находились два старых noindex-макета советов. Они исключены.
- Копии index (1).html … index (9).html исключены через noindex и robots; сохранены их канонические адреса. Они не включаются в проверяемый артефакт публикации.
- У многих страниц были одинаковые description, а часть разделов наследовала заголовок главной. Метаданные исправлены без изменения видимых H1 или текстов статей. JavaScript сохраняет технически подготовленный title.
- У большинства статей отсутствовала Article/BreadcrumbList разметка; услуги не имели общего Service-описания. Добавлен единый JSON-LD-граф с фактическими контактами и территорией обслуживания. Цены Offer берутся только из pricing-data.js и уже существующих предложений; отзывы и рейтинги не выдумывались.
- У двух самостоятельных страниц работ отсутствовал путь от главной через обычные HTML-ссылки. Их поисковые описания теперь автоматически извлекаются из настоящих страниц и добавляются в существующие карточки раздела «Советы». Меню и стиль карточек сохранены.
- Список советов теперь присутствует в исходном HTML, а не возникает только после запуска поиска.
- Добавлена собственная страница 404 с существующей шапкой/стилями; серверный статус 404 проверяется отдельно.

- 37 канонических публичных URL в автоматически создаваемой карте сайта. Это количество технически открытых страниц, а не количество страниц, проиндексированных Google.
- lastmod по изменению содержимого/метаданных с сохранением состояния. Повторная сборка без изменений не меняет дату. Неизвестные даты первой публикации не придуманы.
- Общий robots.txt для Google, Яндекса, Bing, поисковых/пользовательских роботов OpenAI, Perplexity и Claude. Технические разделы исключены. Исходное разрешение обучения через wildcard для GPTBot и ClaudeBot не менялось; это самостоятельная политика.
- Автоматические canonical, Open Graph, Twitter-метаданные, WebSite/WebPage, Article, Service, BreadcrumbList, ImageObject и прайс OfferCatalog там, где они соответствуют содержимому.
- /llms.txt — экспериментальный указатель по реальным страницам.
- /api/public/v1.json — статический JSON только для чтения: услуги, ориентировочные цены, материалы, фотографии и способы связи. Нет заказчиков, закрытой статистики, платежных реквизитов клиентов или административных операций.
- index.md рядом с каждой публичной страницей; HTML содержит rel=alternate. Это автоматически обновляемые представления исходного HTML.
- Публичный файл подтверждения IndexNow; после успешной публикации и проверки сайта workflow отправляет изменённые/удалённые адреса, сохраняет ответ сервиса. HTTP 202 означает ожидание проверки ключа, а не индексацию.
- Проверки sitemap/XML, JSON-LD, внутренних ссылок/ресурсов, основного HTML, уникальности метаданных, пути от главной, контактов, живого поиска и калькуляторов. Отчёты сохраняются в GitHub Actions.
- Существующий GitHub-доступ и процесс редактирования сохранены. В README описаны черновики через отдельную ветку/PR, проверка и публикация с подтверждением владельца. Публичного административного API/MCP-сервера не создано.

37 страниц, 621 внутренних ссылок, 895 ссылок на локальные ресурсы — без отсутствующих целей (цифры — из scripts/seo/check.mjs для этой версии). Проверены 29 маршрутов общего рендерера, сохранение SEO-title после JavaScript, кликабельный телефон, подсказки поиска. Проверки расчёта цены, скидки, поездки, пустого начального калькулятора, полного экрана/чека и сохранённых расчётов проходят. Пройдены существующие расчётные тесты насосов, скважин, генераторов и бойлеров. CSS, pricing-data.js и калькуляторные движки не менялись.

Живые проверки после публикации выполняются workflow `Verify live publication and notify IndexNow`; его артефакт содержит конкретные URL, время и HTTP-ответы. Сохранение артефакта не означает автоматического подтверждения индексации.

## Остаётся владельцу / ограничения

1. **GitHub → Settings → Pages → Source → GitHub Actions.** Однократное переключение необходимо, чтобы сборка и проверки стали обязательным барьером перед выкладкой и чтобы публиковался только подготовленный артефакт. До переключения сохранена прежняя публикация из ветки; проверки запускаются, но не могут остановить независимую старую выкладку. Подготовленный workflow автоматически определяет режим.
2. Реальная индексация, выбранные Google canonical и mobile-first crawl не подтверждены: подключённый GSC Wizard вернул `payment_required` (пробный период завершён/нет подписки). Платный сервис не обязателен: это можно посмотреть в обычной бесплатной Google Search Console. Карта сайта — https://vasilico.ru/sitemap.xml. Google Indexing API для обычных статей не используется.
3. Кабинет Cloudflare, события WAF и настоящие IP-адреса роботов недоступны в текущем подключении. Общая защита не отключалась. Подстановка User-Agent при проверке HTTP не является проверкой подлинности робота.
4. Core Web Vitals по реальным пользователям не измерены; Lighthouse/CrUX и скорость из российских мобильных сетей требуют отдельного измерения. Мобильные viewport/CSS сохранены, дизайн не переделывался.
5. Для старых статей без подтверждённых дат и видимого авторского блока не выдуманы даты/биография. При новых публикациях стоит указывать настоящую дату и автора в существующем оформлении.
6. Нет гарантии сроков индексации, ранжирования и цитирования ИИ. llms.txt и Markdown — дополнительные каналы, не обязательный стандарт поисковых систем.
