# vasilico.ru — готовый статический сайт

Полная копия текущего сайта на 6 октября 2026 года. Все исходные страницы, CSS, JavaScript и изображения сохранены без изменения. Сборка, npm, база данных и сервер ChatGPT не нужны.

## Загрузка на GitHub Pages

1. Распакуйте ZIP на компьютере.
2. Откройте репозиторий для этого сайта в своём GitHub. Если там пока только тестовая заглушка, замените её файлами из архива.
3. Через Add file → Upload files загрузите СОДЕРЖИМОЕ распакованной папки: index.html, CSS, JS, изображения и все папки. Не загружайте сам ZIP и не помещайте сайт во вложенную папку. Подтвердите Commit changes.
4. Убедитесь, что файл CNAME содержит vasilico.ru. Файл .nojekyll также должен лежать в корне; если проводник его скрыл, создайте через Add file → Create new file.
5. Settings → Pages → Build and deployment: Source — Deploy from a branch; Branch — main (или фактическая ветка с файлами); Folder — / (root). Save.
6. Custom domain — vasilico.ru. Дождитесь успешной проверки DNS и выпуска сертификата. Включите Enforce HTTPS, когда настройка станет доступна.
7. Откройте https://vasilico.ru/ и несколько внутренних страниц напрямую. Проверьте поиск в Советах, калькулятор, фотографии и кнопки связи на телефоне без VPN.

## Важное о размещении

Это проект для корня домена vasilico.ru. Пути /style.css, /sovety/ и другие намеренно сохранены: на собственном домене они работают. Предпросмотр по адресу username.github.io/имя-репозитория/ без собственного домена потребовал бы отдельной адаптации путей.

DNS и подтверждение владения доменом на GitHub настраиваются отдельно. Наличие CNAME в архиве не подтверждает, что DNS или публикация уже настроены. Не заменяйте проверочный TXT случайным значением.

Для локального просмотра запустите в папке сайта: python -m http.server 8000
Откройте http://localhost:8000/ . Открытие index.html двойным щелчком не является проверкой сайта: абсолютным путям нужен веб-сервер.

## Содержимое

index.html — главная; style.css — оформление; app.js — страницы и навигация; knowledge.js — статьи и поиск; calculator.js — калькулятор; water-entry.js — эффект воды. Папки uslugi, sovety, ceny, kontakty, o-mastere, raboty и photos содержат страницы и фотографии. Старые материалы также сохранены. robots.txt и sitemap.xml уже используют vasilico.ru.

Внешние переходы оставлены только по назначению, например в мессенджеры. Секретов, учётных данных и служебной конфигурации Sites в архиве нет.
